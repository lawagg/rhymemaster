\# Рифмомастер



Веб-приложение для поиска рифм и работы с ритмикой стиха.



\## Что это



Две части: простая форма для быстрого поиска рифм и студия PRO с холстом куплета.



\## Что реализовано



Корпус сленга 14437 слов. Контекстный корпус 14470 фраз. Word2Vec v3 дообучена. Navec 500k слов. Морфология сленга. G2P модель. RUAccent. Метод Брика. Каскадный семантический мост.



Прототип студии index.html работает в браузере без бэкенда.



\## Требования



Python 3.12, NeMo 2.0.0, PyTorch CPU, Linux или Windows.



\## Зависимости



torch, nemo\_toolkit, gensim, pymorphy3, natasha, ruaccent.



\## Установка



Создать venv через uv, активировать, установить зависимости pip.



\## Структура



Файлы проекта: README.md, PASSPORT.md, TZ.md, index.html и модули Python.



\## Использование



Модули slang\_morph.py, phoneme\_pipeline.py, hybrid\_bridge.py. Студия открывается двойным кликом по index.html.



\## Лицензия



Личный проект.
