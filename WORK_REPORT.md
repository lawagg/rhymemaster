# Отчет о работе над базой (25.10.2026)

## 🏆 Что пробовали и НЕ сработало (Важно!)
1. **Использование `accents.json` как источника истины.** 
   *Почему провалилось:* Словарь содержит массу ошибок (потерянная буква «ё», неверные ударения вроде `т+акая` вместо `такАя`). Любая автоматика, опирающаяся на него, портит базу.
2. **Использование DeepSeek API (LLM) для расстановки ударений.**
   *Почему провалилось:* Нейросеть галлюцинирует (например, ставит `нАлево`, `живЕт` без ё). Она не подходит для строгой фонетики.
3. **Использование `silero-stress` вслепую.**
   *Почему провалилось:* Модель хороша, но иногда ошибается на кратких прилагательных (например, `подводнЫ` вместо `подвОдны`).
4. **Скрипты массовой замены без `flush()` и проверки на дубли.**
   *Почему провалилось:* Привели к падению процесса и созданию битого файла базы на 407 МБ.

## ✅ Что сработало
1. **Метод «Голосования большинства» (Majority Vote).**
   Сравниваем старую базу от `ruphon`, вывод `silero-stress` и `accents.json`. Если 2 из 3 согласны — берем этот вариант. Это починило ~19 700 слов.
2. **Ручной фикс для спорных слов.**
   497 слов, где все инструменты разошлись во мнениях, сохранены в `controversial_words.txt` (ожидают ручной проверки).
3. **Создание `homographs_enriched.json`.**
   Омографы (войны/войнЫ) теперь имеют падежи, чтобы скорер выбирал правильное ударение после предлогов.
