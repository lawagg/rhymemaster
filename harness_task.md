# Задание

Прочитай файл из INPUT_FILE. В нём слова, в каждом + стоит перед ударной гласной (пример: чи+ллить).

Для КАЖДОГО слова сгенерируй ВСЕ возможные морфологические формы, перенося + в нужное место каждой формы:

- Существительные: 6 падежей × 2 числа; с приставками (не-, без-, сверх-); с уменьшительными суффиксами, если реальны.
- Прилагательные: 6 падежей × 3 рода × 2 числа; краткая форма; степени сравнения; с приставками.
- Глаголы: инфинитив; наст./буд. (1/2/3 л. × ед./мн.); прош. (м./ж./ср./мн.); повелит. (ед./мн.); возвратная форма; причастия (наст./прош., действ./страд., все роды/числа/падежи); деепричастия (наст./прош.); с приставками (по-, за-, на-, до-, от-, при-, у-, вы-, пере-, про-, с-, раз-, под-, над-, об-, из-, воз-, в-, вз-, недо-, пре-) — для каждой приставки, дающей реально существующий глагол, вся парадигма.
- Наречия/междометия: базовая форма + производные, если есть.

Правила:
1. + в каждой форме строго перед ударной гласной.
2. Включай все формы — и уверенные, и сомнительные.
3. Помечай confident: true/false.

Сохрани результат в OUTPUT_FILE в формате:
{"чи+ллить": {"pos": "VERB", "forms": [{"form": "чи+ллил", "features": "прош. м.", "confident": true}]}}

Параметры (задаются при запуске):
- INPUT_FILE = путь к файлу со словами
- OUTPUT_FILE = путь для результата
