# TODO: Приставочные формы глаголов

Статус: отложено, требует проверки (17.10.2026)

## Проблема

В slang_clean_v2.json только базовые формы глаголов (ебать, чилить, блядовать).
Нет приставочных: заебать, наебать, въебать, поебать, почилить, зачилить и т.д.

## Решение 1 (приоритет): лемматизация при запросе

Проверить, лемматизирует ли pymorphy3 приставочные сленговые формы.
Если да — генерация форм не нужна, всё решается на лету.

Команда для теста:
cd ~/models
python3 -c "
import pymorphy3
morph = pymorphy3.MorphAnalyzer()
for w in ['почилить', 'зачилить', 'поблядовать', 'въебать', 'уебать', 'чилить', 'ебать']:
    parses = morph.parse(w)
    if parses:
        p = parses[0]
        print(f'{w:<15} -> {p.normal_form:<15} (score: {p.score:.2f})')
    else:
        print(f'{w:<15} -> не знает')
"

## Решение 2 (если лемматизация не работает): strip_prefix

Функция отрезает приставку, если остаток есть в словаре.

prefixes = ['вы','до','за','на','недо','о','пере','по','пре','при','про','у',
            'в','вз','воз','из','над','об','от','под','пред','раз','с']

Правило твёрдого знака:
- Приставки на гласный (вы,до,за,на,недо,о,пере,по,пре,при,про,у) — без ъ
- Приставки на согласный (в,вз,воз,из,над,об,от,под,пред,раз,с) — ъ,
  если корень начинается на е,ё,ю,я (въебать, съебать, объебать, разъебать)

## Что НЕ работает как фильтр

- Navec/W2V: пропускают реальные приставочные (почилить, поблядовать)
- FastText: слишком снисходителен, даёт вектор для любого слова
- pymorphy3: сленг не знает
- slang_morph.py: работает по шаблонам, не для приставок

Вывод: автоматически отличить реальное почилить от нереального вчилить нельзя.
